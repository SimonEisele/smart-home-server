Wo finde ich den Link?
Outlook (Microsoft 365, Outlook.com)
Outlook im Browser öffnen → Einstellungen ⚙ → Kalender → Freigegebene Kalender → «Kalender veröffentlichen»: Kalender und «Kann alle Details anzeigen» wählen → Veröffentlichen → den ICS-Link kopieren.
Google Kalender
calendar.google.com → Einstellungen → links den Kalender wählen → «Kalender integrieren» → «Privatadresse im iCal-Format» kopieren.
iCloud (iPhone, Mac)
Kalender-App → Kalender teilen → «Öffentlicher Kalender» einschalten → Link kopieren (beginnt mit webcal://).

Der Link ist wie ein Passwort: Wer ihn hat, sieht die Termine. Die WG sieht ihn nie.

So abonnierst du ihn
Outlook
Kalender → «Kalender hinzufügen» → «Aus dem Internet abonnieren» → Link einfügen.
Google Kalender
Links bei «Weitere Kalender» auf + → «Per URL» → Link einfügen.
iPhone
Oben «Auf iPhone/Mac abonnieren» antippen, oder Einstellungen → Kalender → Accounts → Account hinzufügen → Andere → «Kalenderabo hinzufügen».

Outlook im Browser und Google holen den Kalender über das Internet ab. Das klappt nur, wenn die App von aussen erreichbar ist. Ist sie nur im WLAN zu Hause erreichbar, funktioniert das Abo nur auf Geräten im selben Netz (z. B. Outlook am PC, iPhone).
